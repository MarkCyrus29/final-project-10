# Airline Reservation System - Frontend

This is the frontend client for the Airline Reservation System built using React and Vite.

## Tech Stack
- **React (Vite)**
- **React Router DOM**
- **Tailwind CSS**
- **Axios**
- **React Hook Form + Yup**

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview production build:
   ```bash
   npm run preview
   ```
